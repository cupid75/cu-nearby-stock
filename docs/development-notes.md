# 해결한 문제와 개선 과정

이 문서는 소스와 2026-10-17~19 작업 기록을 바탕으로 정리했습니다. 당시 연결 결과를 현재 재고나 오늘의 재검증 결과로 해석하지 않습니다.

| 문제 | 개선 내용 | 설계 의도 |
|---|---|---|
| 상품·지도·목록이 한 화면에 있어 스크롤이 길어짐 | 상품 검색 메인과 결과 화면 분리, 메인 복귀 제공 | 각 단계에서 필요한 정보에 집중 |
| 빠른검색에서도 상품을 다시 골라야 함 | 이름이 유일하게 일치하면 결과로 바로 이동 | 중복 선택을 줄이되 여러 후보는 직접 선택 |
| 위치 선택 후 재고 버튼을 다시 눌러야 함 | 위치가 있으면 상품 선택 후 1회 자동 조회 | 기존 위치를 활용하고 GPS 재요청 방지 |
| GPS 실패 안내만으로 원인을 알기 어려움 | 권한 거절·위치 불가·시간초과 등 안내 구분, 동네 검색 제공 | 실패 원인에 맞는 다음 행동 안내 |
| 지도에 긴 매장명 표시가 겹침 | 수량 중심의 작은 핀과 선택 매장 상세 카드 | 지도 가독성과 상세 정보 확인을 함께 지원 |
| 일반 브라우저 형태의 CU 요청이 거절됨 | 앱 요청 형태를 조사하고 서버 요청 함수에 반영 | 확인된 요청 방식 재사용. 지속 지원은 보장하지 않음 |
| Windows 터미널 종료 시 서버도 함께 종료됨 | 별도 프로세스 실행기와 상태·종료 명령 제공 | 초보자도 실행 상태를 확인하고 종료 가능 |
| 연결 실패를 품절로 오해할 수 있음 | 재고 있음·품절·미확인·오류 분리 | 조회에 실패한 결과를 확정 수량으로 표시하지 않음 |
| 같은 조건으로 외부 요청이 반복됨 | 짧은 캐시와 요청 제한, 자동 재시도 제외 | 외부 요청 수와 부하 감소 |

## 검증 범위

- `tests/test_app.py`: 가짜 CU 응답으로 상태·거리·캐시·오류·요청 제한 등을 검사합니다.
- `tests/ui_fixture_server.py`: 가상 위치·재고로 화면을 살펴보는 도구입니다. 실제 서비스의 조회 결과가 아닙니다.
- 과거 공개 브라우저 검사에서는 지도·장소 검색·상품 검색·재고 조회·화면 이동과 작은 화면의 가로 넘침 여부를 확인했습니다.
- 실제 휴대폰에서 GPS·한글 키보드·지도 터치·길찾기를 모두 검증한 기록은 없습니다. PC 브라우저 화면 크기 검사와 구분합니다.
- 현재 시점의 CU 연결은 `verify_live.py` 또는 공개 화면으로 별도 확인해야 합니다. 실패 시 반복 호출하지 않습니다.

## 저장소 정리 기준

2026-10-20 기준, 실행 소스와 배포 설정은 유지하고 처음 설치하는 방법·설계·개선 과정을 문서로 추가했습니다. 자동 검사와 로컬 실행·연결 확인 도구도 포함했습니다.

개인 작업 인수인계, 원문 재고 결과 JSON, 화면 캡처, 배포 ZIP, 설치 환경과 실행 로그는 공개 저장소의 필수 자료가 아니므로 업로드 대상에서 제외했습니다. `.gitignore`는 앞으로 추가될 파일을 제외하는 규칙이며, 이미 Git에 등록한 비밀 자료를 자동 삭제하거나 파일 내용의 비밀키를 탐지하는 기능은 아닙니다.
